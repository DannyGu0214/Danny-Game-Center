# Ocean World 3D — P4 소리 보고서 (W2)

작성 2026-11-18 · 브랜치 `claude/ocean-world-3d-w2-sound` · 지시 `docs/brief-w2-sound.md`

외부 음원 파일 없이 Web Audio 합성만으로 배경음악 1곡, 생물 소리 8종, 게임 효과음 4종을 만들고 켜기·끄기·음량 저장을 연결했어요. 초안은 이전 칸이 썼고(커밋 전 중단), 이번 칸이 검토·수정·확인을 마쳤어요.

표기: **[확인]** = Node 또는 브라우저에서 실제로 실행해 본 것 · **[추정]** = 코드와 수치로 본 판단(귀로 듣지 않음)

## 1. 바꾼 것

| 파일 | 상태 | 내용 |
|---|---|---|
| `audio/sound.js` | 수정 | `attachSound(fx)`: 첫 `pointerdown`/`keydown` 뒤 AudioContext 생성, `visibilitychange`로 배경음악 정지·재개, `localStorage('ow3d-sound')` 저장·복원(try/catch), `fx.game.on`으로 6종 사건 구독, `{ muted, setMuted, volume, setVolume }` 반환 |
| `audio/music.js` | 새 파일 | 배경음악 1곡(32마디, F 장조, 86 BPM)과 미리 예약하는 방식의 스케줄러 |
| `audio/sfx.js` | 새 파일 | 생물 8종(`SPECIES_VOICES`), 게임 효과음 4종(`GAME_SFX`), 0.1초 중복 방지(`DEDUP_SEC`) |
| `docs/p4-sound-report.md` | 새 파일 | 이 보고서 |

이번 검토에서 고친 것:
- `music.js`: 멈춘 뒤 곧바로 다시 틀면, 멈추기 전에 최대 0.25초 앞까지 예약해 둔 음이 다시 커진 볼륨으로 겹쳐 울렸어요. 이제 재생할 때마다 새 출력 노드를 만들고, 멈출 때 쓰던 노드는 소리를 줄인 뒤 연결을 끊어요.
- `sfx.js`: 바다거북은 같은 높이의 두 음이 겹쳐 렌더 최대 진폭이 0.37로 다른 종(0.13~0.25)보다 컸어요. 피크를 0.22/0.16에서 0.15/0.11로 낮춰 0.26이 됐어요 [확인: OfflineAudioContext 렌더].

`render/`, `ui/`, `index.html`, `sim/`, `eco/`, `vendor/`, `test/`, 다른 게임 폴더는 고치지 않았어요.

## 2. 곡 구성

- 제목 `산호초의 아침` · **F 장조 · 4/4 · 86 BPM · 32마디**(한 바퀴 약 89.3초) [확인]
- 형식 A–A'–B–C(각 8마디)

| 구간 | 마디 | 코드 진행 |
|---|---|---|
| A 주제 | 1~8 | `Fmaj7 Am7 Dm7 Bbmaj7 Fmaj7 Gm7 Bbmaj7 C7` |
| A' 마침 | 9~16 | `Fmaj7 Am7 Dm7 Bbmaj7 Gm7 C7 Fmaj7 Fmaj7` |
| B 햇살 석호 | 17~24 | `Bbmaj7 C7 Am7 Dm7 Bbmaj7 Am7 Gm7 C7` |
| C 돌아옴 | 25~32 | `Dm7 Am7 Bbmaj7 Fmaj7 Gm7 C7 Fmaj7 Fmaj7` |

- 악기(사인·삼각파 위주): 마림바 멜로디(사인 + 금방 사라지는 4배음), 벨 아르페지오(사인 + 2.76배음, 16·32마디는 쉼), 패드(±5센트 어긋난 삼각파 둘, 720Hz 로우패스), 둥근 베이스(1박·2.5박·3.5박), 아주 작은 셰이커(9~28마디). B구간은 멜로디에 벨을 겹쳐요.
- 음량: 마스터 아래에서 배경음악 버스 `0.3`, 효과음 버스 `0.9`. 기본 음량은 `0.75`예요.

## 3. 종별 소리 설계

`adopt`, `tapCreature` 때 재생해요. 길이·높이는 OfflineAudioContext로 렌더해 잰 값이에요(길이 = 최대 진폭의 1%를 넘는 마지막 지점, 높이 = 앞 0.12초 자기상관) [확인].

| id | 이름 | 길이 | 주된 높이 | 설계 |
|---|---|---|---|---|
| `seacucumber` | 해삼 | 0.23초 | 210Hz | 낮은 사인이 올랐다 내려오고 삼각파 꼬리, '물컹-뽀옥' |
| `hermitcrab` | 소라게 | 0.25초 | 848Hz | 짧은 삼각파 3연타 + 잡음 딸깍, '똑-똑-따각' |
| `anemone` | 말미잘 | 0.35초 | 459Hz | 떨림 있는 사인 상승 + 맑은 3음, '파르르-뾰롱' |
| `clownfish` | 흰동가리 | 0.20초 | 711Hz | 빠른 사인 2음, '뽀글-삐!' |
| `octopus` | 문어 | 0.26초 | 152Hz* | 짧은 상승 '뽁' + 삼각파 하강 + 바람 잡음, '휘리릭' |
| `moonjelly` | 보름달물해파리 | 0.35초 | 394Hz | 느린 떨림의 사인 + 옥타브, '뽀요옹~' |
| `greenturtle` | 바다거북 | 0.36초 | 168Hz | 로우패스 삼각파 + 사인 저음 + 끝 숨소리, '뿌우웅' |
| `manta` | 쥐가오리 | 0.40초 | 149Hz | 천천히 부푸는 저음 + 오르는 물결 잡음, '우우웅-샤아' |

\* 문어는 음높이가 위아래로 크게 미끄러져서, 자기상관 값은 대표값이 아니에요.

모두 지시서 범위(0.2~0.6초) 안이에요. 구별: 높은 쪽(소라게·흰동가리·말미잘·해파리)은 높이와 리듬(3연타 / 2음 / 떨림 상승 / 긴 떨림)이 서로 달라요. 낮은 쪽 넷 가운데 **거북과 쥐가오리는 높이(168Hz와 149Hz)와 길이가 가까워요**. 둘은 음색(삼각파+숨소리 / 느린 부풀림+물결 잡음)으로만 갈려요 [추정].

게임 효과음:

| 사건 | 설계 |
|---|---|
| `place` | 뭍(`zone: 'land'`)은 '톡', 물속(`bed`/`water`)은 물방울 '퐁' |
| `capture` | 짧은 셔터 딸깍 + F장조 상승 4음(`first`면 5음) |
| `tier` | 마림바+벨 상승 6음 + 저음 받침, 약 1.1초 팡파르 |
| `chance` | A5→C6 두 음, 피크 0.05로 아주 작게 |

중복 방지: 같은 종(`sp:<id>`)이나 같은 효과음(`sfx:<이름>`)이 `ac.currentTime` 기준 0.1초 안에 다시 오면 건너뛰어요.

## 4. 확인함

- `npm test`: **78/78 통과** [확인]
- Node(가짜 AudioContext): 곡 32마디·86 BPM 컴파일됨. `eco/atoll/data.js`의 SPECIES 8종 키와 `SPECIES_VOICES` 키가 일치함. 0.1초 중복 방지 `[같은 종 0.05초 뒤 → 막힘, 다른 종 → 남, 0.11초 뒤 → 남, tier 0.04초 뒤 → 막힘]`. window·localStorage가 없어도 `attachSound`가 계약 객체를 돌려주고, 음량은 0..1로 잘림 [확인]
- 브라우저: `python3 -m http.server 8798` + headless Chrome(임시 프로필, chrome-devtools MCP), `index.html?title=0&prologue=0` [확인]
  - 누르기 전: AudioContext 생성 **0개**. `__ow.sound` 키 `muted, setMuted, volume, setVolume`. 기본값 `muted false`, `volume 0.75`.
  - 첫 클릭(실제 사용자 동작, '해삼 ⭐15' 단추) 뒤: AudioContext **1개**, `state running`, 배경음악 예약 시작.
  - 사건 발행: 8종 `tapCreature`, `place`(land·water), `capture`, `tier`, `chance`가 모두 오실레이터를 만듦(종마다 2~4개, tier 14개).
  - 같은 종 `adopt` 연속 2회에서 두 번째는 0개, 다른 종은 바로 재생, 0.15초 뒤 같은 종은 다시 재생.
  - `setMuted(true)`: 0.6초 동안 효과음·배경음악 오실레이터 0개. `setMuted(false)`: 배경음악 다시 예약됨.
  - `setVolume(7)` → 1, `setVolume('abc')` → 값 그대로, `setVolume(0.35)` → localStorage에 `{"muted":false,"volume":0.35}` 저장.
  - `visibilitychange`(`document.hidden`을 덮어써 흉내): 숨김 중 1초 동안 오실레이터 0개 + context `suspended`, 돌아오면 다시 예약 + `running`.
  - `muted true`, `volume 0.35`로 바꾸고 새로고침: 둘 다 유지됨. 음소거 상태에서 클릭하면 AudioContext는 열리지만 오실레이터는 0개. 음소거를 풀자 1초에 18개가 예약됨.
  - 콘솔: **JS 오류·예외 0건**. 남은 오류 로그는 `favicon.ico` 404뿐이에요(페이지 로드마다 1건, `index.html`에 아이콘이 없어서).
