## 1. 바꾼 것

| 파일 | 내용 |
|---|---|
| `render/core/jelly.js` | 이전 Gemini 칸이 고친 내용(커밋 안 된 것)을 검토해 이어 씀. 진폭 상한 `maxAmp = 0.03`(위상 공간 상한 + 매 단계 자르기), 연타 간격 `cooldown = 0.2`초, 가드 `setGuard(fn)`·잠금 `setLocked`, `nudge`(같은 탭의 전단 방향), `justPoked`, `onUpdate` 고리, 강성·감쇠 조정(약 1.5Hz, 1초 안에 가라앉음). 이번에 고친 것은 두 가지예요. ① `poke(…, {force:true})`는 연타 간격만 건너뛰고, 가드(놓기 모드·카메라 회전)는 늘 지킴(Gemini 판은 가드까지 뚫었음). ② 가드가 걸리면 남은 출렁임을 약 0.15초 만에 지수로 가라앉힘(갑자기 멈춰 튀지 않게). 매 프레임 `Vector3`를 새로 만들던 것도 재사용으로 바꿈 |
| `render/core/deform.js` | Gemini 판을 그대로 씀. `SQUASH` 조각에 말미잘 촉수 오므림(`aParams.z`, 부위 `aDef.z > 1.5`)을 더함. `aParams.z`를 쓰던 종은 없음(grep으로 확인) |
| `ui/react.js` | 반응 7가지와 경계를 구현함(2절). `attachReact`가 `{ setLevel, level, active }`를 돌려줌 |
| `ui/settings.js` (새) | 오른쪽 위 ⚙️ 단추 하나로 여는 창 "출렁임: 보통 / 약하게 / 끄기". `localStorage['ow3d.jellyLevel']`에 저장하고 try/catch로 감쌈. 타이틀·프롤로그(`body.intro`)와 녹화 모드에서는 숨김 |
| `docs/p4-jelly-report.md` (새) | 이 보고서 |

강도 값: 보통 1 · 약하게 0.45 · 끄기 0. 물결은 보통 1 · 약하게 0.6 · 끄기 0.35 배율로, 끄기에서도 누른 것이 받아들여졌다는 표시로 작게 남겨요. 주소에 `?jelly=`를 준 경우와 녹화 모드는 저장값 대신 주소 값을 따라요.

## 2. 반응 7가지별 구현

| 사건 | 구현 | 길이 |
|---|---|---|
| `tapBlock` 빈 곳 누름 | `input.js`가 먼저 주는 `poke(-0.7)`이 받아들여졌을 때만(`justPoked`) 누른 자리 → 블록 가운데 방향으로 `nudge`(가장자리일수록 셈). 누른 격자 자리에 `hf.disturb` 동심원 물결 | 약 1초 감쇠 |
| `adopt` 들임 | 생물 인스턴스 행렬의 높이만 덧씌워 수면 위 3.2칸(육지형 1.6칸)에서 가속하며 떨어뜨림. 수면을 지나는 순간 물결, 다 떨어지면 작은 블록 눌림. 육지형(`z ≥ 0`)은 착지 때 몸 눌림("통") | 0.5초 |
| `place` bed·land | 놓은 물건의 조각 행렬에 바닥 기준점에서 세로 눌림(부피 1차 보존) `press(u)`를 덧씌움. 끝나면 `propView._place`로 원래 행렬로 되돌림. 블록은 흔들지 않음 | 0.4초 |
| `place` water | 물건 높이 기준점에서 수평축으로 두 번 까딱(±0.2rad, 감쇠). 떠 있는 물건은 수면 기울기 위에 덧씌움 | 0.6초 |
| `tapCreature` | 해파리·문어·해삼·말미잘만 그 개체의 `aParams.w`(스쿼시)를 눌렸다 올라오게, 말미잘은 `aParams.z`(촉수 오므림)도 함께. 같은 개체를 0.2초 안에 다시 누르면 새로 시작하지 않음. 블록은 흔들지 않음 | 0.36초(말미잘 0.5초) |
| `tier` | 다음 프레임에 `poke(-0.9, 0.3, 0.18, {force})` + 가운데 큰 물결. 놓기 확정 안에서 티어가 오르면 놓기 모드가 끝난 다음 프레임에 반응 | 약 1초 |
| `expandStart`·`expand` | `render/main.js`가 이미 연출하므로 구독하지 않음 | — |

경계
- 놓기 모드(`game.isPlacing()`)와 카메라 회전(OrbitControls `start`~`end`) 중에는 `jelly` 가드가 `poke`·`drag`를 거절하고, 남은 출렁임은 빠르게 가라앉혀요.
- 진폭 상한은 `jelly.maxAmp` 0.03(블록 높이 대비 전단·눌림), 0.2초 안 연타 무시.
- 포착(`capture`)은 생물을 누른 탭에서 생기므로 블록을 흔들지 않게, 4차 준비 때 있던 `capture` 블록 눌림을 뺐어요(DESIGN 4.3 ✨).
- 판정은 그대로예요. 생물 `creatures.drawn`, 물건 `pickList`, 규칙 좌표는 건드리지 않고 화면 행렬만 덧씌워요.
- 덧씌우는 방법: `creatures.update`와 `propView.update`가 매 프레임 행렬을 다시 쓰므로, `react.js` 안에서 두 함수 뒤에 고리를 이어 붙였어요(`after()`). `main.js`를 고치지 않으려고 고른 방법이에요.

## 4. 추정 (실행하지 않은 것)

- "보이는 느낌"(퐁·쫀득·까딱이 자연스러운지)은 수치로만 봤고, 대니님 노트북에서 직접 보지는 않았어요.
- 녹화 모드(`?capture`)에서 반응 7가지를 프레임별로 저장해 보지는 않았어요. 시간 기준이 `jelly.time`(=`app.step` dt)이라 녹화 모드의 `step`과도 맞을 것으로 봐요.
- 문어·해삼 누름은 해파리와 같은 경로라 따로 재지 않았어요.
- T8 확장과 티어 상승이 같은 프레임에 겹칠 때 `main.js`의 확장 `poke`는 연타 간격(0.2초)에 걸려 빠질 수 있어요(진폭은 상한이 같아 차이가 작음).
- 터치 기기(두 손가락, 짧은 탭)는 재지 않았어요.

## 5. 메인에 요청

- 디버그 창(`#ui`)의 젤리 슬라이더(0~2)는 설정 창과 따로 놀아요. 슬라이더를 움직이면 `jelly.strength`가 바뀌지만 설정 표시는 그대로예요. 슬라이더를 없애거나 `react.setLevel`과 잇는 것은 `main.js`·`index.html` 쪽이라 고치지 않았어요.
- 확장 연출(`main.js`의 `jelly.poke`)도 같은 가드를 따르게 돼요. 놓기 확정 안에서 확장이 시작되면 그 순간의 `poke`는 거절돼요. 확장 출렁임을 꼭 넣으려면 `main.js`에서 다음 프레임으로 미루거나 `{ force: true }`를 주는 방법이 있어요(`force`도 가드는 지킴).
- 드로우콜 기준값 19를 20으로 고칠지 확인해 주세요(base도 20).

## 6. 남은 문제

- 해저·육지 물건의 "모래 먼지 조금"은 넣지 않았어요. 입자를 더하면 드로우콜이 늘어서예요.
- 중층 물건의 "줄이 팽팽해지며"는 까딱 하나로 대신했어요.
- 대왕조개(물건 `giantclam`) 외투막 닫기는 지시 범위(생물 4종) 밖이라 넣지 않았어요.
- `creatures.update`·`propView.update` 뒤에 이어 붙이는 방식은 두 함수 이름이 바뀌면 함께 고쳐야 해요.
