# 퀴즈퀴즈 2026

90년대 TV 가족 예능 같은 도트 무대에서 A팀과 B팀(2인조)이 6분야 문제로 겨루는 가로 화면 퀴즈 게임이에요. 설계는 [DESIGN.md](DESIGN.md)에 있어요.

## 지금 되는 것 (M1 첫 조각)

- 처음 실행하면 2인조 팀을 골라요. 그 팀으로 리셋 전까지 대회를 이어 가고, 전적과 승수 칭호가 쌓여요.
- 혼자 하기(컴퓨터 실력 살살·보통·진심)와 둘이 하기(기기 하나, 가로 화면).
- 정규전: 오프닝 → 1부 몸풀기(분야 돌림판, 4지선다 6) → 2부 분야 판(6분야 × 100·200칸, 8칸) → 3부 역전 한 방(주관식) → 동점이면 서든데스 → 시상식.
- 기회 규칙(차례 팀 → 상대 팀 → 한 번씩 더), 4지선다·글자 조각 주관식·숫자 입력, ③부터 초성 힌트.
- 도트 화풍(2026-11-14 대니님 확정): C '브라운관 대결형' 배치, '오락실 원색', 2~2.5등신 치비. 진행자 왕대박·나정답(부스 뒤에서 고개만), 도우미 반짝이, 듀오 2쌍, VS 폭발과 정답 클로즈업, 고무 닭·종·꽃가루.
- 칩튠 효과음 37종(펄스파·삼각파·노이즈 합성)과 배경음악 루프. 설정에서 소리 끄기, 효과음·음악 음량을 따로 바꿔요. `index.html?sfx=1`로 열면 효과음을 하나씩 눌러 들어 볼 수 있어요.
- 문제는 팀 실력과 상관없이 나와요(2026-11-14 대니님 결정). 컴퓨터는 실력별 등급 정답률이 정해져 있어요.

## 실행

ES 모듈이라 정적 서버로 열어요.

```bash
cd games/quiz-quiz-2026 && python3 -m http.server 8797
```

문제은행은 `bank/index.js`(문제은행 담당 칸)가 있으면 그걸 쓰고, 없으면 테스트용 샘플 `test/fixtures/bank/`(출처 대조 전 시범 60문항)로 돌아요.

## 테스트와 봇 대전

```bash
npm test                                   # 규칙·한글 처리 테스트
node tools/sim-match.mjs --skill normal    # 사람 승률·판 길이·3부 역전률
node tools/sim-match.mjs --part3 300       # 3부 배점을 바꿔 보기
```

## 파일

| 파일 | 내용 |
|---|---|
| `logic.js` | 한 판 진행, 기회 규칙 표, 점수, 문제 고르기(팀 실력과 무관), 컴퓨터 팀(등급별 고정 정답률), 팀 전적·칭호 |
| `hangul.js` | 초성, 정규화·채점, 글자 조각 |
| `art.js` | 480×270 도트 무대와 출연진 |
| `sound.js` | 효과음과 칩튠 |
| `main.js`, `index.html` | 화면 흐름, 입력, 저장 |
| `tools/sim-match.mjs` | 봇 대전 |
