# 좀비 아웃포스트 (Zombie Outpost)

세로 화면·쿼터뷰 모바일 웹 게임이에요. 필드에서 근접 무기와 총으로 좀비와 싸우며 자원을 직접 파밍하고, 기지·전진기지를 키우고, 구출한 동료에게 방어·생산·탐험 임무를 맡겨요. 쓰러지면 처음부터 다시 시작하는 로그라이크예요.

자세한 규칙과 수치는 [DESIGN.md](DESIGN.md)에 있어요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면·조작·HUD·효과음·저장(브라우저 저장소, claude.ai에서는 계정 클라우드 저장) |
| `logic.js` | 게임 규칙 전부(화면 없음, 고정 시간 단계 1/30초, 시드 난수) |
| `art.js` | 그림 전용(쿼터뷰 도형으로 땅·지형지물·건물·캐릭터를 그림) |
| `music.js` | 배경음악 7곡 합성(Web Audio, 파일 없음) |
| `test/logic.test.js` | 규칙 테스트 |
| `tools/sim.js` | 균형 측정용 봇 시뮬레이션 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 독립 실행(PWA): 홈 화면 설치·오프라인 실행 |

## 휴대폰에 설치

GitHub Pages 주소를 열고 브라우저 메뉴에서 **홈 화면에 추가**(iPhone은 Safari 공유 버튼 → 홈 화면에 추가)를 누르면 앱처럼 설치돼요. 한 번 열어 두면 인터넷 없이도 실행돼요. 저장은 그 기기·브라우저에만 남아요.

## 실행

```bash
python3 -m http.server 8791
```

브라우저에서 `http://localhost:8791`을 열어요. 소리는 첫 터치 뒤에 켜져요.

## 테스트

```bash
npm test
```

## 봇 시뮬레이션

```bash
node tools/sim.js 60 7
```

인자는 플레이 시간(분)과 시드예요.
