# My Little Cafe

회사를 그만두고 은퇴를 앞둔 사장님의 작은 카페를 물려받는 세로 화면 모바일 게임이에요. 커피를 전혀 몰라도 사장님에게 배우면서 할 수 있어요. 지금은 **스토리 모드와 봄 20일 본게임**까지 있어요. 여름부터는 만들고 있어요. 기획과 수치는 [DESIGN.md](DESIGN.md)에 있어요.

**바로 하기:** https://dannygu0214.github.io/Danny-Game-Center/games/my-little-cafe/

## 조작

- 시작할 때 주인공, 사장님, 카페 위치, 카페 이름을 골라요.
- 대사는 화면을 탭하면 넘어가요. 프롤로그는 건너뛸 수 있어요.
- 제조는 화면 위 안내를 따라요. 초록 칸에 맞추면 돼요.
- 맛 저울이 왼쪽이면 시큼해서 더 곱게, 오른쪽이면 써서 더 굵게 갈아요.
- 위의 📖 노트에 배운 내용이 저절로 쌓여요.
- 스토리를 끝내면 타이틀에 오피스 가게와 동네 가게가 함께 열려요. 저장은 가게마다 따로예요.
- 위의 🏠 가게를 누르면 가게 앞과 가게 안을 언제든 볼 수 있어요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면·시작 선택·대사·결과 카드·시험·저장·게임 루프 |
| `data.js` | 카페 이름, 메뉴, 레시피 기준값, 날마다 분쇄 칸, 인물 표 |
| `story.js` | 프롤로그부터 엔딩까지 진행표와 대사, 커피 노트, 손님 반응 |
| `logic.js` | 제조 판정과 진행 규칙(화면 없음) |
| `stations.js` | 제조 8단계(갈기·담기·다지기·샷·물·스팀·뜸·붓기)의 그림과 손 조작 |
| `tilt.js` | 다지기용 폰 기울임 읽기(방향 센서, 아이폰 허용) |
| `assets.js`, `assets/` | 이미지 모델로 만든 인물·배경·물건 그림(WebP)과 표정 고르기 |
| `art.js` | 대화 화면과 이야기 장면 합성 |
| `art-shop.js` | 가게 외관과 점내 합성, 코드로 그리는 작은 인물 |
| `floor.js` | 손님 동선과 좌석 규칙(화면 없음) |
| `business.js` | 본게임 규칙: 날씨, 손님 도착, 자동 잔, 매출, 평판, 장비, 결산(화면 없음) |
| `main-mode.js` | 본게임 화면: 아침 준비, 메인 모드 주문판, 단골 대화, 마감, 결산 |
| `music/` | 날씨별 배경음악 8곡(sunoapi.org 생성, 80kbps) |
| `music.js`, `sound.js` | 음악 2곡과 제조 소리 합성 |
| `test/` | 규칙·진행표·문구 말투·손님 동선 테스트 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 독립 실행(PWA). 아이콘은 이미지 모델로 그린 커피잔 |

## 실행

```bash
python3 -m http.server 8796
```

브라우저에서 `http://localhost:8796`을 열어요.

점검용 주소:
- `?dbg=1`이면 `window.MLC`가 생겨요(`MLC.start(선택, 날, 줄)`, `MLC.run(초)`).
- `?auto=1&place=office`(또는 `home`)면 대사와 제조를 자동으로 넘겨 엔딩까지 가요. 저장을 덮어써요.
