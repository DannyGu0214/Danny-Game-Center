# Sailing Master

배를 설계해 작은 호수에서 대양까지 항해하는 세로 화면 모바일 게임이에요. 전투는 없고 자연이 위협이에요. 지금은 **담수 세 수역**(작은 호수 → 큰 호수 → 강)까지 플레이할 수 있어요. 기획과 측정값은 [DESIGN.md](DESIGN.md)에 있어요. 다음 작업 기획은 [PLAN-M1.5.md](PLAN-M1.5.md)(체계 심화)와 [PLAN-M2.md](PLAN-M2.md)(앞바다)예요.

**바로 하기:** https://dannygu0214.github.io/Danny-Game-Center/games/sailing-master/

## 조작

- 시작할 때 선장 4명 중 한 명을 고르면(특성이 달라요) 출항 이야기가 나오고 갈대 나루에서 시작해요.
- 물을 탭하면 그곳으로 자동으로 가요(맞바람이면 지그재그). 항구·수문·표류물을 탭하면 거기로 가요.
- 아래 키 슬라이더를 끌면 직접 몰아요. 놓으면 키가 가운데로 돌아와요.
- 돛 내림·줄임·전체, 노 켜고 끄기. 선장이 그 자리로 걸어가요(갑판원이 있으면 바로 돼요).
- 물 위의 통나무·천 뭉치는 재료, **금빛으로 반짝이는 곳**은 교역품이에요. 항구에서 팔고, 공방에서 재료를 윗급으로 바꿔요.
- 선원은 모듈이 만든 자리에 앉아야 일해요. 선원 탭 평면도에서 카드를 누르고 자리를 눌러 앉혀요. 편성(항해·폭풍·입항)과 위임 규칙도 거기 있어요.
- 지나가는 생물을 탭하면 도감에 기록돼요.
- 화면 끌기로 둘러보기, 두 손가락(데스크톱은 휠)으로 확대·축소.
- 아래 메뉴: 해도(항해 계획·예보) · 배 · 선원 · 도감 · 도전과제. 항구에서는 항구 칸이 더 생기고 조선소·설계·꾸미기·고용까지 해요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면·조작·HUD·시트(항구·조선소·설계·꾸미기·선원·해도·기록)·저장·게임 루프 |
| `art-story.js` | 선장 출항 이야기 그림 12장(캔버스) |
| `data.js` | 수역·선체·모듈·역할·선장·이야기·생물·도전과제 표와 상수 |
| `logic.js` | 게임 규칙 전부(화면 없음, 고정 시간 단계 1/30초, 시드 난수) |
| `ship.js` | 배 설계 규칙: 칸 검사, 무게·복원력·속도 계산 |
| `world.js` | 수역 지도: 물가 거리 격자·항로 찾기·물살·여울·나무 배치 |
| `art.js` | 물·땅·나무·항구·표류물·항적·날씨 그림 |
| `art-ship.js` | 층 쌓기 배 그림(선체·모듈)·돛·사람·노 |
| `creatures.js` | 생물 19종 움직임과 그림 |
| `music.js`, `sound.js` | 배경음악 mp3 재생(못 읽으면 합성곡 3곡), 파도·바람 소리와 효과음 합성 |
| `test/logic.test.js` | 규칙 테스트 |
| `tools/sim.js` | 밸런스 봇: `node tools/sim.js [시드] [최대 분] [v]` |
| `tools/ship-preview.html` | 방향 8개 × 상태 5개 배 점검표(`?zoom=10`, `&hull=rowboat`) |
| `tools/sound-check.html` | 소리 크기 오프라인 측정 |
| `tools/icon.html` | 앱 아이콘 그리기 |
| `assets/` | 선장 초상화·이야기 그림·배경음악 mp3(출처는 `assets/CREDITS.md`) |
| `docs/asset-manifest.yaml`, `docs/art-style.md` | 에셋 목록과 화풍 기준(agent-bridge 의뢰용) |
| `manifest.webmanifest`, `sw.js`, `icons/` | 독립 실행(PWA) |

## 실행

```bash
python3 -m http.server 8795
```

브라우저에서 `http://localhost:8795`를 열어요. `?fps=1`이면 프레임 수, `?dbg=1`이면 점검용 `window.SM`이 생겨요.
