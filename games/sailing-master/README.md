# Sailing Master

배를 설계해 작은 호수에서 대양까지 항해하는 세로 화면 모바일 게임이에요. 전투는 없고 자연이 위협이에요. 지금은 **네 수역**(작은 호수 → 큰 호수 → 강 → 앞바다)까지 플레이할 수 있어요. 앞바다의 조선 항구에서 4등급 **스쿠너**를 지어 북쪽 큰 바다 경계를 넘으면 이번 단계의 엔딩이에요(M2 끝, 큰 바다는 M3). 기획과 측정값은 [DESIGN.md](DESIGN.md)에 있어요. 다음 작업 기획은 [PLAN-M1.5.md](PLAN-M1.5.md)(체계 심화)와 [PLAN-M2.md](PLAN-M2.md)(앞바다)예요.

**바로 하기:** https://dannygu0214.github.io/Danny-Game-Center/games/sailing-master/

## 조작

- 시작할 때 선장 4명 중 한 명을 고르면(특성이 달라요) 출항 이야기가 나오고 갈대 나루에서 시작해요.
- 물을 탭하면 그곳으로 자동으로 가요(맞바람이면 지그재그). 항구·수문·표류물을 탭하면 거기로 가요.
- 아래 키 슬라이더를 끌면 직접 몰아요. 놓으면 키가 가운데로 돌아와요.
- 돛 내림·줄임·전체, 노 켜고 끄기. 선장이 그 자리로 걸어가요(갑판원이 있으면 바로 돼요).
- 물 위의 통나무·천 뭉치는 재료, **금빛으로 반짝이는 곳**은 교역품이에요. 항구에서 팔고, 공방에서 재료를 윗급으로 바꿔요.
- 선원은 모듈이 만든 자리에 앉아야 일해요. 선원 탭 평면도에서 카드를 누르고 자리를 눌러 앉혀요. 편성(항해·폭풍·입항)과 위임 규칙도 거기 있어요.
- 날씨: 해도·항구 예보 칸과 위쪽 계기판에 돌풍·폭풍·소나기·안개·무더위·홍수·가뭄이 보여요. 돌풍·폭풍엔 돛을 줄여요(다 펴고 버티면 돛이 찢어져요). 찢어지면 아래 **🧵 돛 꿰매기** 단추(화물칸 마포 2장)나 항구 보급 칸에서 꿰매요. 비에는 그늘막이 식량을 지켜 줘요.
- **앞바다(짠물):** 바닷물은 못 마셔요. 사람마다 하루 식수 1통(무더위 2통)이라 설계에서 **물통**(4통)을 달고 항구 보급 칸에서 **💧 채우기**로 사요(등대섬은 비싸요). 떠다니는 물통도 건져요. 민물 항구에 대면 물통을 공짜로 채워요. 위쪽 칸에 💧 남은 식수와 🌊 물때가 보여요.
- **너울:** 곶 밖 바깥 바다는 너울이 높고 만 안쪽은 잔잔해요. 너울이 배의 내항성(등급·별·바닥짐)을 넘으면 느려지고 상하고 짐이 쓸려 가요. 옆으로 맞으면 더 상하니 뱃머리를 너울(북쪽)에 맞대요. **방수 격벽**은 피해를 절반으로 줄이고 물보라에서 식량을 지켜요. 예보 칸 아래 〰 숫자가 그날 바깥 바다 너울이에요.
- **조수:** 하루에 밀물·썰물 두 번(±0.6m). 썰물엔 모래톱이 드러나 걸려요. 해도·항구의 물때 줄에서 다음 썰물·밀물까지 남은 시간을 봐요. **해무**는 새벽 바다를 덮고, 등대섬 불빛 가까이는 옅어요.
- **앞바다 발견지:** 10곳. 바다 동굴은 썰물(물때 −0.25m 밑)에만 들어가고, 조수 웅덩이는 썰물에만 드러나요. 동굴에서 **조수기** 설계도(항해 중 바닷물을 하루 2통 식수로), 해안 난파선에서 **스쿠너** 설계도가 나와요.
- **스쿠너(4등급):** 슬루프 ★2부터 **조선 항구**(조선소 4등급)에서 지어요. 철판·톱니·베어링은 앞바다에서 나오고, 앞바다 항구는 잡목·참나무·범포·철판·톱니를 팔아요. 돛대를 둘(앞돛대 = 돛대, 주돛대) 세우고, 타륜·망루·구명정을 달 수 있어요. 일손(선원)이 셋이 안 되면 돛을 줄인 만큼만 펴요. 맞바람·약한 바람엔 연료 없는 **보조 기관**이 느리게 돌아요.
- 지나가는 생물을 탭하면 도감에 기록돼요. 돌고래가 배 앞을 탈 때(금빛 고리) 탭하면 도전과제예요.
- 화면 끌기로 둘러보기, 두 손가락(데스크톱은 휠)으로 확대·축소.
- 위쪽 오른쪽 소리 단추: 음악·소리(효과음)·물바람을 슬라이더로 따로 조절하고 켜고 꺼요. 값은 기기에 저장돼요.
- 아래 메뉴: 해도(항해 계획·예보) · 배 · 선원 · 도감 · 도전과제. 항구에서는 항구 칸이 더 생기고 조선소·설계·꾸미기·고용까지 해요.

| `art-story.js` | 선장 출항 이야기 그림 12장(캔버스) |

| `logic.js` | 게임 규칙 전부(화면 없음, 고정 시간 단계 1/30초, 시드 난수) |

| `world.js` | 수역 지도(호수·강·해안 모양): 물가 거리 격자·항로 찾기·물살·여울·조수 수심·너울 자리·나무 배치 |

| `art.js` | 물·땅·나무·풍경 사물·항구·표류물·항적·날씨 그림 |

## 실행

```bash
python3 -m http.server 8795
```

브라우저에서 `http://localhost:8795`를 열어요. `?fps=1`이면 프레임 수, `?dbg=1`이면 점검용 `window.SM`이 생겨요.
