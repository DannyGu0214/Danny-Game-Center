# Sailing Master

배를 설계해 작은 호수에서 대양까지 항해하는 세로 화면 모바일 게임이에요. 전투는 없고 자연이 위협이에요. 지금은 **M0 손맛 시제품**이라 호수 하나에서 슬루프로 돛과 노를 몰아 볼 수 있어요. 기획과 측정값은 [DESIGN.md](DESIGN.md)에 있어요.

## 조작

- 물을 탭하면 그곳으로 자동으로 가요(맞바람이면 지그재그).
- 아래 키 슬라이더를 끌면 직접 몰아요. 놓으면 키가 가운데로 돌아와요.
- 돛 내림·줄임·전체, 노 켜고 끄기.
- 화면 끌기로 둘러보기, 두 손가락(데스크톱은 휠)으로 확대·축소.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면·조작·HUD·게임 루프 |
| `data.js` | 시점·배·돛 효율·바람·자동 항로 상수 |
| `logic.js` | 항해 규칙(화면 없음, 고정 시간 단계 1/30초) |
| `world.js` | 호수 윤곽·물가 거리 격자·항로 찾기·나무 배치 |
| `art.js` | 물·땅·나무·항적 그림 |
| `art-ship.js` | 층 쌓기 배 그림·돛·선장·노 |
| `sound.js` | 파도·바람 소리와 효과음 합성 |
| `test/logic.test.js` | 규칙 테스트 |
| `tools/ship-preview.html` | 방향 8개 × 상태 5개 배 점검표(`?zoom=10`) |
| `tools/sound-check.html` | 소리 크기 오프라인 측정 |

## 실행

```bash
python3 -m http.server 8795
```

브라우저에서 `http://localhost:8795`를 열어요. `?fps=1`이면 프레임 수, `?dbg=1`이면 점검용 `window.SM`이 생겨요.
