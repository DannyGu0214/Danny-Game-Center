# Sailing Master 에셋 스타일 기준

이 문서가 Sailing Master 에셋의 스타일 기준이에요. 에셋 목록은 [asset-manifest.yaml](asset-manifest.yaml)에 있어요.

## 세계관

- 대항해시대(16~18세기) 유럽·남미풍 항구 도시에서 출발해 호수 → 강 → 바다 → 대양으로 나가는 항해 이야기예요.
- **싸움이 없어요.** 해적, 무기, 피, 해골 같은 것은 넣지 않아요.
- 분위기는 따뜻하고 활기차며, 거친 뱃사람의 낭만이 있어요. 너무 귀엽지도, 너무 어둡지도 않아요.

## 캐릭터 초상화

- **화풍**: 반실사 디지털 유화. 붓 터치가 보이는 그림책·게임 일러스트 느낌이에요. 사진처럼 보이면 안 돼요.
- **구도**: 가슴 위 흉상, 정면에서 살짝 돌린 3/4 각도. 얼굴은 위쪽 3분의 1에서 가운데쯤에 둬요.
  - 게임 카드는 가로로 긴 비율(약 16:10)이라 정사각 원본의 위아래가 잘릴 수 있어요. 얼굴부터 어깨까지는 가로 16:10으로 잘라도 남는 범위(세로 중앙 62%) 안에 둬요.
- **빛**: 해 질 녘이나 등불의 따뜻한 옆빛.
- **배경**: 흐릿하게 처리한 항구 부두, 돛대, 물. 인물보다 어둡고 채도를 낮게 해요.
- **옷**: 대항해시대풍 코트. 색은 선장마다 정한 `coat` 색을 주색으로 써요. 머리카락 색과 모양도 아래 표를 따라요.
- **네 장의 통일감**: 같은 화풍·빛·배경 계열로 맞춰 한 세트로 보이게 해요.
- **금지**: 글자, 로고, 워터마크, 테두리, 무기, 실존 인물이나 영화·게임 캐릭터를 닮은 얼굴.

## 배경음악

- 지금 게임에 있는 곡은 Web Audio로 합성한 선술집 풍 3곡이에요(`music.js`, DESIGN.md 32절). 새 mp3는 이 3곡을 같은 수역·분위기로 대체해요.
- **공통 악기**: 아코디언, 피들, 만돌린처럼 뜯는 현, 콘트라베이스, 나무 바닥 발 구르기, 탬버린.
- **연주 공간**: 나무 벽 선술집 정도의 짧은 울림.
- **공통 조건**: 보컬 없는 연주곡이에요. 반복 재생할 때 끝에서 처음으로 끊김 없이 이어져야 해요. 귀엽거나 동요 같은 느낌은 피해요.
