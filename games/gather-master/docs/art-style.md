# 줍줍 마스터 화풍 기준 — "몽글 저폴리"

- 상태: 초안 · 2026-11-25. 에셋 목록(`docs/asset-manifest.yaml`)과 생성 요청은 모두 이 문서를 기준으로 해요.
- 한 줄 정의: **둥글고 포근한 저폴리, 파스텔 색, 머리가 큰 동물 주민, 부드러운 햇빛.** 장르 감성(포근한 생활 게임)만 가져오고, 특정 게임의 모습은 가져오지 않아요.

## 1. 금지 사항 (먼저 읽기)

> 특정 기존 게임(예: 동물의 숲)의 캐릭터·디자인·고유 외형·UI·이름을 **베끼거나 연상시키도록 맞추지 않아요.** 이름·캐릭터·UI·아이콘은 모두 우리가 새로 만들어요.

| 하지 않는 것 | 대신 |
|---|---|
| 특정 게임의 캐릭터, 종족+직업 조합 모방: 너구리 상점 주인, 부엉이 박물관장, 강아지 비서, 멧돼지 순무 장수 | 우리 주민은 3절의 새 조합으로 정해요. 다른 게임에서 특정 역할로 유명한 종족(예: 재봉사 고슴도치, 경고하는 두더지)은 그 역할로 쓰지 않아요 |
| 나뭇잎 모양 로고·아이콘, 비행장·섬 이주 패키지 설정, 휴대전화 앱 메뉴 | 우리 상징은 **곡괭이·도끼·새싹을 합친 둥근 배지**(P3에서 디자인) |
| 화폐 "벨"·"마일" 같은 고유 명칭, 주가처럼 오르내리는 순무 가격 | 화폐는 **코인**, 가격은 고정(시제품) |
| 알아들을 수 없는 웅얼거림 목소리, 특정 게임의 말풍선 모양(이름표가 붙은 둥근 말풍선) | 말풍선은 **나무판 표지판 모양**, 목소리는 짧은 효과음 |
| 특정 게임 화면을 프롬프트·참고 이미지로 쓰기("○○ 스타일로") | 프롬프트에는 이 문서의 단어(파스텔·저폴리·둥근 모서리)만 써요 |
| 실존 게임 글꼴·UI 프레임 복제 | 공개 글꼴(예: Google Fonts의 둥근 고딕)과 우리 UI |

점검: P3 화풍 검토 때 이 표를 항목별로 대조하고, 위반 0을 완료 기준에 넣어요(`PLAN.md`).

## 3. 모양 언어와 비율

- **둥근 모서리**가 기본이에요. 모서리 반경은 물체 크기의 10% 이상이고, 뾰족한 끝은 무기류에도 쓰지 않아요.
- 실루엣은 큰 덩어리 **3개 이하**로 만들어요(예: 나무 = 줄기 + 잎 뭉치 2개).
- 면은 적게(저폴리) 쓰되, 매끈한 법선으로 부드럽게 보여요. 각진 면 음영은 바위·광석에만 써요.
- 크기 기준: 플레이어 키 1m, 나무 2.2~2.8m, 바위 0.8~1.2m, 집 1단계 2m → 5단계 6m.
- **주민·플레이어 비율**: 약 2.5등신. 머리가 전체 키의 45%이고, 몸통은 짧고 팔다리는 뭉툭해요. 눈은 작은 점이나 짧은 타원이고, 볼에 연한 홍조 원을 둬요.
- 주민 후보(오리지널, P3에서 확정): 판매함 관리인 **오소리**, 도구 장인 **비버**, 씨앗 가게 **다람쥐**. 1절 금지 목록의 종족·역할 조합과 겹치지 않는지 확정 전에 다시 봐요.
- 플레이어도 동물 주민 하나(색만 고를 수 있게)로 시작하는 안을 P3에서 정해요.

## 4. 조명·그림자 (three.js 0.187 기준 출발값)

| 항목 | 값 |
|---|---|
| 하늘·땅 반사광 | `HemisphereLight(#CDEBFF, #A8D88E, 0.9)` |

| 그림자 | `PCFSoftShadowMap`, 지도 1024(휴대폰 512), 플레이어 주변 30m만 비춰요. 그림자 색은 거의 검정이 아니라 보라 기운으로 보이게 반사광을 남겨요 |
| 톤 매핑 | `NeutralToneMapping`, 노출 1.05, `SRGBColorSpace` |
| 안개 | `Fog(#DDEFFF, 40, 90)` — 먼 곳을 파스텔로 흐리게 |
| 재질 | `MeshStandardMaterial`, 거칠기 0.85~1, 금속성 0(광석만 0.3). 정점 색으로 아래쪽을 10~15% 어둡게 해서 가짜 그늘을 줘요 |
| 선택 | 3단계 `MeshToonMaterial` 셀 음영은 P3에서 A/B 비교해 정해요 |
