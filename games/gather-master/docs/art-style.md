# 줍줍 마스터 (Gather Master) 화풍 기준 — "몽글 저폴리"

- 상태: 2판 · 2026-11-25(사람 주인공·얼굴·복장·지형 추가). 에셋 목록(`docs/asset-manifest.yaml`)과 생성 요청은 모두 이 문서를 기준으로 해요.
- 한 줄 정의: **둥글고 포근한 저폴리, 파스텔 색, 머리가 큰 동물 주민, 부드러운 햇빛.** 장르 감성(포근한 생활 게임)만 가져오고, 특정 게임의 모습은 가져오지 않아요.

## 1. 금지 사항 (먼저 읽기)

> 특정 기존 게임(예: 동물의 숲)의 캐릭터·디자인·고유 외형·UI·이름을 **베끼거나 연상시키도록 맞추지 않아요.** 이름·캐릭터·UI·아이콘은 모두 우리가 새로 만들어요.

| 하지 않는 것 | 대신 |
|---|---|
| 특정 게임의 캐릭터, 종족+직업 조합 모방: 너구리 상점 주인, 부엉이 박물관장, 강아지 비서, 멧돼지 순무 장수 | 우리 주민은 3절의 새 조합으로 정해요. 다른 게임에서 특정 역할로 유명한 종족(예: 재봉사 고슴도치, 경고하는 두더지)은 그 역할로 쓰지 않아요 |
| 나뭇잎 모양 로고·아이콘, 비행장·섬 이주 패키지 설정, 휴대전화 앱 메뉴 | 우리 상징은 **곡괭이·도끼·새싹을 합친 둥근 배지**(P4에서 디자인) |
| 화폐 "벨"·"마일" 같은 고유 명칭, 주가처럼 오르내리는 순무 가격 | 화폐는 **코인**, 가격은 고정(시제품) |
| 알아들을 수 없는 웅얼거림 목소리, 특정 게임의 말풍선 모양(이름표가 붙은 둥근 말풍선) | 말풍선은 **나무판 표지판 모양**, 목소리는 짧은 효과음 |
| 특정 게임 화면을 프롬프트·참고 이미지로 쓰기("○○ 스타일로") | 프롬프트에는 이 문서의 단어(파스텔·저폴리·둥근 모서리)만 써요 |
| 특정 게임 주인공의 얼굴 부품·머리 모양 목록·옷 카탈로그를 그대로 옮기기 | 3-1절의 우리 프리셋(이름·조합)만 써요 |
| 실존 게임 글꼴·UI 프레임 복제 | 공개 글꼴(예: Google Fonts의 둥근 고딕)과 우리 UI |

점검: P4 화풍 검토 때 이 표를 항목별로 대조하고, 위반 0을 완료 기준에 넣어요(`PLAN.md`).

## 3. 모양 언어와 비율

- **둥근 모서리**가 기본이에요. 모서리 반경은 물체 크기의 10% 이상이고, 뾰족한 끝은 무기류에도 쓰지 않아요.
- 실루엣은 큰 덩어리 **3개 이하**로 만들어요(예: 나무 = 줄기 + 잎 뭉치 2개).
- 면은 적게(저폴리) 쓰되, 매끈한 법선으로 부드럽게 보여요. 각진 면 음영은 바위·광석에만 써요.
- 크기 기준: 주인공 키 1.1m, 동물 주민 0.8~1.2m, 나무 2.2~2.8m, 바위 0.8~1.2m, 집 1단계 2m → 5단계 6m.
- **동물 주민 비율**: 약 2.5등신. 머리가 전체 키의 45%이고, 몸통은 짧고 팔다리는 뭉툭해요. 눈은 작은 점이나 짧은 타원이고, 볼에 연한 홍조 원을 둬요.
- 주민·동료 후보(오리지널, P4에서 확정): 오소리 보리(위탁상점), 거북 느림보 할배(장터), 다람쥐 도토(씨앗), 동료 비버 통통·고양이 나비·염소 매애·오리 꽥순·곰 뭉치·생쥐 콩알(`DESIGN.md` 8절). 1절 금지 목록과 겹치지 않는지 확정 전에 다시 봐요.

## 3-2. 지형 표현

- 계단식 층 사이 **절벽**은 둥근 모서리 띠(반경 0.4m)와 가로 지층선 2~3줄이에요. 색은 바위 `#B9B4C7`에서 위로 갈수록 밝아져요.
- **경사로**는 흙길 색 `#E8C9A0`이고, 가장자리에 풀 경계를 둬요.
- **물가**: 얕은 물은 바닥이 비치는 `#8FD3E8`, 깊은 물은 `#5FB2D4`예요. 물가에는 거품 선과 갈대 덩어리를 둬요.
- **동굴**: 바탕은 `#4E4A6E` 계열 어두운 보라예요(순수 검정 금지). 등불 반경 6m 안만 따뜻한 `#FFD59A` 빛이에요. 광맥은 반짝이는 정점 색으로 표시해요.
- **폭포**: 흰 거품 띠 + 반투명 물 띠 2장을 스크롤해요.
