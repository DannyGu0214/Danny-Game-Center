# Animal World v2 (중단됨)

> **중단(2026-11-11 대니님 결정)**: 이 2D 렌더러 전환 작업은 여기서 멈췄어요. 새 프로젝트 **Ocean World 3D**(`games/ocean-world-3d/`)를 3D로 처음부터 만들기로 했기 때문이에요.
> Animal World의 다음 버전은 v1이나 이 폴더를 이어 가지 않고, **Ocean World 3D에서 만든 3D 기반을 모태로** 개발하는 방향이에요.
> 이 폴더의 코드와 문서는 기록으로 남겨요. 게임센터 첫 화면에는 올리지 않고, 아래 내용은 중단 시점 그대로예요.

Animal World의 렌더러를 PixiJS(WebGL 2D 렌더링 라이브러리)로 바꾸고, 노트북 가로 화면과 바닷속·땅속 단면을 더하려던 버전이에요. 계획은 [PLAN.md](PLAN.md)에 있어요.

- 중단 시점 상태(2026-11-10): **M0 측정 장면 · M1 PixiJS 시제품**까지 만들었어요. 게임 전체가 PixiJS로 그려지고 그대로 플레이할 수 있어요. 노트북 실측은 하지 않았어요(PixiJS가 실제로 더 빠른지는 확인하지 못했어요).
- 나중에 다시 쓸 만한 것: 리그 스프링 시간 상한(느린 프레임에서 몸 일부가 튀어나가는 v1 문제의 해결책, `index.html`의 `RIG_DT`), 측정 장면과 측정 모음(`perf.js`, `tools/perf-suite.html`).

## 노트북에서 재는 법(M0·M1)

1. 서버를 켜고 Chrome으로 `tools/perf-suite.html`을 열어요.
2. 창을 최대로 키우고 **[시작]**을 눌러요. 끝날 때까지 이 탭을 앞에 두세요(뒤로 가면 브라우저가 프레임을 줄여서 값이 틀려요). 전원 어댑터를 꽂아 두면 값이 안정돼요.
3. 끝나면 나오는 글을 [복사]해서 Claude에게 붙여 주세요. Safari로도 한 번 재 주면 좋아요.

측정 장면 주소 옵션(`index.html?perf=1&…`): `region`(지역) · `n`(동물 수, 최대 44) · `zoom`(1~4) · `renderer`(`pixi`·`2d`) · `outline`(`gpu` 셰이더 · `2d` v1 방식으로 만들어 올리기) · `dur`(잴 초) · `time`(`morning`·`day`·`evening`·`night`) · `dpr`(화면 배율) · `sync=1`(GPU가 다 그릴 때까지 기다려 GPU 시간까지 잼) · `atw`(동물 아틀라스 폭, 기본 4096).

표의 구간: `sky` 하늘 · `scene` 깊이 정렬·찍기 준비 · `rig` 동물 리그를 아틀라스에 그리기 · `upload` 아틀라스를 GPU로 올리고 외곽선 만들기 · `render` 실제 그리기 명령(PixiJS) 또는 장면 합성(2D). `sync=1`이 아니면 GPU가 실제로 그리는 시간은 `render`에 다 들어가지 않고 fps에만 드러나요.

## 화면 층(PixiJS 모드)

```
#view  (Canvas 2D)  하늘
#pixi  (WebGL)      땅 → 그림자 → 물건·동물·가리는 칸(깊이 순서) — 시간대 빛 필터
#over  (Canvas 2D)  선택 고리·놓을 자리·파티클·잠긴 섬 표시
HUD·시트 (HTML)
```

탭 판정은 화면 좌표 계산이라 렌더러와 상관없이 `#view`가 받아요.

## v1과 다르게 보이는 점(시제품)

- 그림자를 동물마다 그 깊이에 그리지 않고 땅 바로 위 한 층에 모아 그려요. 앞쪽 물건 위로 뒤쪽 동물 그림자가 올라오지 않아요.
- 선택 고리·놓을 자리·파티클은 맨 위 층이라 시간대 빛을 받지 않아요(밤에도 밝게 보여요).
- 외곽선 두께는 프레임마다 한 값이에요(v1은 동물마다 크기에 따라 조금씩 달랐어요).
- 동물 아틀라스(최대 4096×8192)에 다 못 들어가는 동물은 아직 그리지 않아요. 측정 표 `miss`에 수가 나와요.
- GPU 자원이 회수되는 일(컨텍스트 손실) 복구는 아직 시험하지 않았어요.

## 개발 규칙

| 규칙 | 이유 |
|---|---|
| v1 파일은 고치지 않고 `../animal-world/`에서 `import`해요. 바꿔야 하는 파일만 이 폴더로 복사해요 | 규칙·리그 코드가 두 벌이 되는 것을 줄이고, 합칠 때 차이를 보기 쉽게 |
| 복사한 파일은 아래 표에 원본과 복사 시점(커밋)을 적어요 | 합칠 때 v1에서 그 뒤에 바뀐 내용을 놓치지 않으려고 |
| 저장 키는 v1과 달라요(`animal-world-v2.save`). v2 세이브가 없으면 v1 세이브를 읽어 와서 시작해요(v1 세이브는 고치지 않아요) | 같은 주소(github.io)라 브라우저 저장소를 같이 써서, v2가 v1 세이브를 망가뜨릴 수 있어요 |
| 서비스 워커(오프라인 캐시)는 개발 중에는 켜지 않아요. 합칠 때 v2용으로 다시 만들어요 | v1 오프라인 캐시와 섞이지 않게, 고친 파일이 바로 보이게 |
| PixiJS는 `vendor/`에 버전을 고정해 넣어요(CDN 안 씀) | 오프라인 실행, 버전 고정 |
