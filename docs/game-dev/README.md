## 공통 기술 스택

| 항목 | 내용 |

## 제작 파이프라인

```
설계 문서  →  규칙 코드 + 자동 테스트  →  자동 플레이 측정  →  화면·연출  →  배포
                                                          ↑
                                  생성 에셋(일부 그림·음악)
```

1. **설계 문서 먼저.** 게임마다 설계 문서에 핵심 루프, 수치, 단계 목표를 적고, 바꾼 이유와 측정값을 이어 적어요.
2. **규칙 검증.** 규칙을 화면 없이 테스트해요. 여러 게임에는 자동으로 플레이하는 측정 도구도 있어서 성장 속도, 승률, 엔딩까지 걸리는 시간 같은 값을 재요.
3. **코드로 그리기.** 게임 속 캐릭터, 생물, 지형, 3D 모델은 대부분 코드로 그려요. My Little Cafe의 배경·인물처럼 그림 파일을 쓰는 곳도 있어요.
4. **생성 에셋.** 필요한 그림과 음악은 에셋 목록과 화풍 기준을 정해 생성형 AI로 만든 뒤 변환해서 넣어요. 그림에는 Google Gemini 이미지 모델(3.1 Flash Image, 3 Pro Image), 음악에는 Suno를 썼어요.

## 흐름

2026-10-25에 Zombie Outpost와 Animal World로 시작한 저장소 기록은 11-25까지 여섯 게임 폴더 기준 194커밋이에요. 그 사이 항해, 3D 수족관, 카페, 퀴즈로 장르를 넓혔어요. 그래픽은 Canvas 2D에서 시작해, Animal World의 관찰형 흐름을 Three.js 기반의 3D로 옮긴 Ocean World 3D까지 왔어요.
