# 좀비 아웃포스트 BGM 스타일·스펙 기준 (Suno 생성용)

기존 배경음악 7곡(`games/zombie-outpost/music.js`, Web Audio 합성)을 **곡마다 1:1로** mp3로 바꾼다. 곡 이름·조성·BPM·코드 진행·악기·분위기·층 쌓기 순서를 그대로 옮긴다. 이 문서가 BGM 스타일의 유일한 정의이고, `docs/asset-manifest.yaml`의 `prompt`는 여기서 뽑은 것이다.

## 공통 스타일 (7곡 모두)

- **연주곡(보컬 없음)**, **드럼·퍼커션 없음**(원곡 7곡 모두 드럼이 없다). 느리고 단순한 멜로디, 포스트 아포칼립스 분위기.
- 4마디 = 한 바퀴, 코드는 한 마디에 하나(4박). 처음에는 코드만 깔리고 → 저음 → 멜로디 순으로 **층이 쌓이는** 전개(원곡의 `바퀴 번호 % 4` 구조). 곡 중반 이후 멜로디가 가끔 빠져 한 박 쉬는 느낌.
- **전 곡 공포·좀비 서바이벌 분위기.** (2026-11-08 청취 피드백: 잿빛 들판·녹슨 라디오만 합격, 나머지 5곡은 장조·밝은 분위기라 불일치 → 5곡을 단조·공포로 다시 만든다.) Suno는 프롬프트의 분위기 단어를 그대로 따르므로 `cheerful`, `cozy`, `lullaby`, `harvest`, `campfire folk`, `hopeful`, `warm` 같은 말을 쓰지 않고, `survival horror`, `zombie apocalypse`, `dread`, `eerie`, `unsettling`, `cinematic horror game score`를 넣는다. 악기(피아노·기타·오르골·휘파람·하모니카)는 그대로 쓰되 쓸쓸하고 으스스하게(드문드문, 반음 충돌, 어긋난 오르골).
- 넓은 폐허 느낌의 약한 리버브(원곡 2.6초 잔향). 절정·폭발·큰 다이내믹 변화 없이 **잔잔하게 유지**(게임 소리 위에 깔리는 배경이라 효과음을 덮으면 안 된다).
- 곡끼리 음량이 비슷해야 한다(원곡은 RMS를 맞췄다).

## 파일 규격

| 항목 | 값 |
|---|---|
| 형식 | MP3, 스테레오, 44.1kHz, CBR 128kbps(Suno 원본을 로컬이 변환) |
| 길이 | 목표 약 5:00(원곡은 곡당 5분 재생). 모델이 허용하는 최대 길이까지, 최소 3:30. 끝은 서서히 사라지게(게임이 4초 겹쳐 넘김) |
| 음량 | 7곡 모두 통합 -16 LUFS ±1, 트루 피크 -1 dBTP 이하 |
| 경로 | `games/zombie-outpost/assets/bgm/<번호>-<영문>.mp3` |
| 용량 | 곡당 약 5MB 이하. Git LFS는 쓰지 않는다(GitHub Pages가 LFS 파일을 제대로 서빙하지 못한다) |

## sunoapi.org 요청 기준

- 엔드포인트: `POST /api/v1/generate`, `customMode: true`, `instrumental: true`, 모델은 `V4_5` 이상(최대 길이가 긴 쪽). 실제 모델·비용은 로컬이 `note`에 적는다.
- 필드: `title` = 곡 이름(한글), `style` = manifest의 `prompt`, `negativeTags` = `vocals, singing, choir, drums, percussion, EDM, distorted guitar, heavy bass, cheerful, happy, upbeat, bright, cute, folk pop, lullaby, comedic`.
- 한 번 요청에 두 곡이 나오면 원곡 분위기에 더 가까운 쪽을 고르고, 다른 쪽 URL은 `note`에 남긴다.
- 5곡(3~7번)은 조성을 단조로 바꿨으므로 합성곡 폴백과는 조성이 다르다(곡 이름·BPM·악기·층 쌓기는 1:1 유지). 장조로 나오면 재생성한다.
- Suno는 조성·BPM·코드를 정확히 지키지 못할 수 있다. 큰 차이(조성이 장조↔단조로 뒤바뀜, BPM ±15 이상)가 나면 한 번 더 생성하고, 그래도 어긋나면 `note`에 적고 `done`으로 둔다.
